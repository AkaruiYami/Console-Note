A quiet place for your thoughts

Notes at the speed of a terminal.

Capture a thought, find it later, and keep it as a plain Markdown file. Console Note gives you a focused terminal interface and a full command line.

Simple by design.

Markdown files

Each note lives in its own readable text file, in a directory you choose.

Keyboard first

Open the interactive interface, search your notes, and edit with your preferred editor.

Optional sync

Connect a private GitHub repository to sync notes across devices.

Get started.

Windows installer

Download the installer, run it, then launch Console Note from the Start Menu. The app opens in a terminal window.

Other ways to install

Windows · Scoop

scoop install https://raw.githubusercontent.com/AkaruiYami/Console-Note/main/bucket/console-note.json

Windows · PowerShell

irm https://raw.githubusercontent.com/AkaruiYami/Console-Note/main/install.ps1 | iex

Linux · install script

curl -fsSL https://raw.githubusercontent.com/AkaruiYami/Console-Note/main/install.sh | sh

From source · Cargo

cargo install --git https://github.com/AkaruiYami/Console-Note

Prefer a portable archive? Download it from Releases. See the README for details.

Write a note. Keep moving.

console_note add "An idea" -c "A thought worth keeping"

Run console_note with no arguments for the interactive interface. Your notes stay as Markdown files you can open anytime.
